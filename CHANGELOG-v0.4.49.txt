글클메 애드온 v0.4.49 · 번역·EXP·물약 안정화 / 측정기 명칭 변경

기준: v0.4.48 전체 소스. 기존 번역기·번역 사전·게임 채팅 색상 분류 유지.

[EXP]
- EXP 글자 영역만 픽셀 변화 감지, 변화 시 OCR 우선 재검사, 정지 시 주기적 확인.
- 판독 실패 시 짧은 재시도, EXP 획득량은 실제 읽힌 누적 HUD 수치 차이만 집계.
- 부분 OCR('EXP'만 인식)에 멈추지 않고 숫자 인식을 재시도.
- EXP 루프와 물약/메소 OCR을 독립 스레드로 분리하여 메소 스캔이 EXP를 막지 않음.

[물약]
- 4x3 단축키 패널 자동 탐색 유지, 실패 시 [영역 지정]으로 게임 캡처 사진에서 수동 지정.
- 수동 지정은 게임 클라이언트 상대 좌표로 저장; [재인식] 시 유지, [자동] 시 삭제.
- 등록되지 않은 물약도 슬롯의 아이콘 이미지를 그대로 캡처해 위젯에 표시.
- 수량 영역이 동일하면 짧은 OCR 캐시 사용, 변화/주기 재검사 시 숫자 전용 OCR.
- OCR 판독 불가 수량은 추정값을 사용하지 않음. 재인식 및 화면 변경 시 재탐색.
- 펫 물약 영역은 실제 화면에 수량이 나타나는 경우에만 수동 선택을 검토해야 함;
  본 버전은 4x3 단축키 패널 영역을 선택하는 기능이며 펫 UI 자동 탐지는 구현하지 않음.

[번역]
- 슬라이딩 중복 필터의 짧은 OCR 공백/부분 프레임으로 인한 상태 초기화 완화.
- 같은 텍스트가 실제 신규 줄로 들어온 경우를 보존하고 스크롤된 줄 재출력을 방지.
- 다른 짧은 문장에 잘못 재사용된 시각 해시가 있을 때의 누락을 완화.
- 기존 색상·줄 추적·번역 큐·한글 아이템명 규칙 유지.

[UI]
- '글클메 · 사냥 통계' → '글클메 경험치 측정기'. 설정 메뉴도 '경험치 측정기'.
- 단축키 수동 영역 선택 및 자동 복귀, 재인식 버튼 추가.
- 메이플 위 표시는 유지. 강제 전체 창 위는 고정 ON일 때만.

[검증 범위]
- Python 3 환경 전체 소스 유닛/회귀 테스트, 실제 게임 단축키 fixture 활용.
- 이 환경에 Windows/PySide6/ONNX Runtime 없어 Windows EXE 설치·실게임 측정은 미검증.
- 이전 source ZIP을 별도 설치할 필요 없이 전체 ZIP 한 개에서 BUILD-WINDOWS.bat.
