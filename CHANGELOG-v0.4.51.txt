글클메 애드온 v0.4.51 - 라이브 물약 아이콘·숫자 및 고확 최종 출력 중복 보완

기준: v0.4.50 원본. 이전 기능/번역 사전/경험치 측정 방식 유지.

1. 맨 아래 Ctrl/Del/End/PgDn 슬롯의 왼쪽 숫자 경계를 포함하도록 캡처 영역 확장.
2. 아이콘 스냅샷에서 기존 좌측 약 19% 강제 절단 제거. 단축키 캡션과 수량은 투명 분리.
3. 작은 수량 전용 ROI와 대비 전처리 확대. 1회 고신뢰 판독도 시간차 두 번 확인한 뒤 확정.
4. 화면에서 부여한 물리적 고확 메시지 ID를 번역 큐를 지나 최종 출력까지 유지.
5. 동일 화면 이벤트의 출력 중복을 차단하고, 실제 새 이벤트는 독립 ID를 유지.
6. 출력 ID 기억은 4096개로 제한. 프레임 세션 재설정 시 epoch 충돌 방지.

주의: MetaRoad 비공개 구현을 복제한 것이 아니며, 본 패치는 독립 구현입니다.
      이 환경에서는 Windows EXE 실게임 구동 및 ONNX Runtime OCR 인식률을 검증하지 못함.
      현재 수량이 실제로 인식되는지 Windows 메이플에서 확인 필요.
