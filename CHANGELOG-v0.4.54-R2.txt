글클메 애드온 v0.4.54-R2 / 원본 R1 기반 응급 지연 개선

1. 경험치 측정기: 메소 증감 칸 삭제, 390px -> 344px. 사냥 시간 / EXP / 물약 4칸 / 제어 버튼 유지.
2. 메소 전체 인벤토리 OCR 주기 실행 중단. 물약 수량 OCR과 EXP OCR 유지.
3. 채팅 캡처 프레임 보관 한도 48 -> 12, 심하게 밀릴 때 최신 화면 5개를 우선 처리. 오래된 프레임을 스킵한 횟수 진단 제공(capture_stale_drops). 과밀 채팅에서는 중간 프레임 누락 가능성이 있으므로 현장 검증 필요.
4. 모델 시작 워밍업 EN->KO 우선. KO->EN 입력 번역은 사용 시 준비.
5. 번역 일괄 작업을 최대 8문장 -> 3문장으로 조정해 긴 작업이 짧은 문장을 막는 시간 단축. 실제 번역 대기시간 translation_wait_ms 추가.

주의: 실시간 게임 화면 테스트와 Windows exe 실행/서명 검증은 이 환경에서 미실시. BUILD-WINDOWS.bat으로 윈도우 독립 빌드 가능.
