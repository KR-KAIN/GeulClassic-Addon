KAIN Maple Translator - OBS 설정

1. 프로그램 실행 -> 왼쪽 [OBS 투명 소스 주소 복사]
2. OBS -> 소스 -> + -> 브라우저
3. URL 붙여넣기. 가로 470 / 세로 140 권장.
4. 프로그램 [표시 시험] 버튼으로 OBS 표시 확인.
5. 메이플 -> 번역 ON -> 새 채팅 자동 출력.

OBS 창 캡처 방식:
- 창: KAIN Maple Translator - Chat
- 투명창의 검은 배경 문제가 있으면 위 브라우저 소스를 사용하세요.
- 게임 채팅 영역 위를 번역창이 완전히 가리면 OCR이 방해될 수 있으므로
  게임 옆 자석 모드 + OBS 브라우저 소스를 권장합니다.

항상 위 설정:
- 작은 왼쪽 패널의 톱니바퀴 -> '창 위에 표시 방식'
- 메이플 위에만 (기본) / 항상 위 / 일반 창 (끔)

현재 ZIP은 Windows EXE 완성본이 아닌 독립 Windows 빌더입니다.


[v0.4.6 OBS 전용 고확/일반채팅 높이 조절]
1. OBS 브라우저 소스로 KAIN Maple Translator 주소를 추가합니다.
2. OBS 소스를 우클릭하고 '상호작용'을 선택합니다.
3. 위쪽 '확성기' 영역 아래의 가로 손잡이를 위/아래로 끌어 높이를 바꿉니다.
4. 아래쪽 '일반채팅' 영역 맨 아래 손잡이도 위/아래로 끌 수 있습니다.
5. 손잡이를 더블클릭하면 기본값인 확성기 30% / 일반채팅 70%로 초기화됩니다.
6. OBS 브라우저 소스 전체 크기는 OBS의 소스 속성에서 지정합니다.
※ OBS 안에서만 저장되는 값이며 게임 위 번역창의 높이나 비율에는 영향을 주지 않습니다.
※ 브라우저 소스 저장소를 초기화하면 비율도 초기화됩니다.
