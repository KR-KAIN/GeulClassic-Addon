# 글클메 번역애드온 v0.4.23 — 회색 배경·파란 글씨 확성기 OCR 보강


**기존 v0.4.22 전체 소스를 기반으로 하는 독립 Windows ZIP입니다.** 이전 버전 폴더/실행파일은 필요 없습니다.

## 신규 기능: GMS → KMS 아이템 ID 기반 한국어 명칭 대조 (v0.4.19)

**원리:** 영문 아이템 이름을 GMS/62 목록에서 찾고, 그 아이템의 숫자 ID를 KMS 목록과 조인해서 한글명을 출력합니다. 서로 다른 한국어 이름이 하나의 영어 이름에 걸리면 번역에 반영하지 않습니다. 숫자 ID 일치는 **후보 대응일 뿐 같은 아이템의 공식 한국어 번역을 증명하지 않습니다**. 버전 차이·리네이밍에 유의하세요.

### Windows에서 한 번만 동기화

1. `BUILD-WINDOWS.bat`로 앱 EXE 빌드가 정상 완료됐는지 먼저 확인하세요.
2. 인터넷에 연결된 상태에서 **`UPDATE-GMS-KMS-ITEMS.bat`**를 실행하세요. (빌드와는 별도의 작업)
3. 프로그램의 `ITEM-SYNC-REPORT.txt`를 읽어 `ITEM-SYNC PASS`, 영문 총량, 한국어 총량, ID 대응 수, 모호한 영문명 제외 수를 확인하세요.
4. 결과 데이터는 `%LOCALAPPDATA%\KAINMapleTranslator\gms-kms-item-names.json`으로 저장합니다. 앱 다음 채팅 번역부터 읽고, 수동 가져오기 용어집은 건드리지 않습니다.
5. API 실패·연결 끊김·ID 대응 부족 시 기존 정상 DB는 **절대 덮어쓰지 않습니다**.

기본 경로는 `GMS/62`와 `KMS/65`를 대조합니다. KMS v65의 실제 지원 여부는 아직 확인되지 않았으므로 연결할 수 없거나 너무 적은 항목을 반환하면 **KMS/284를 순차 시도**합니다. 어떤 버전이 선택됐는지 보고서와 로컬 DB에 기록됩니다. 특정 KMS 버전을 선택하려면 Python 3.11+에서 `python scripts\sync_gms_kms_items.py --kms-versions 65` 같은 형태로 직접 실행하세요.

**중요: 출처·권리.** 이 스크립트는 maplestory.io의 *게임 아이템 명칭 데이터*만 사용자의 명시적인 실행 시 한 번 호출합니다. 제3자 Planet Helper/메이플노트는 수집하지 않습니다. MapleStory Network는 교육·비영리 및 공정 이용 성격의 API 활용을 권장하며, 저작권·넥슨의 권리를 존중해야 한다고 안내합니다. 상업용 배포/데이터셋 재판매는 별도 권리 확인이 필요합니다. 자세히: https://maplestory.net/develop/disclaimer/

**검증 상태:** API 라우팅 코드는 공개 서버 소스로 검증했지만, 이 작업 환경에서는 `maplestory.io`의 라이브 응답을 읽을 수 없었습니다. 실제 몇 개가 대응될지는 `UPDATE-GMS-KMS-ITEMS.bat`를 실행해야 알 수 있습니다. 검증 데이터·모의 네트워크로 비교 동작을 시험했으며, Windows 게임 현장은 미검증입니다.

## 실행

1. ZIP 파일 하나를 **새 폴더에 전부 압축 해제**하세요.
2. 맨 위 폴더의 **`BUILD-WINDOWS.bat`**만 실행하세요. 내부 `scripts`의 Python 파일은 EXE 빌드 버튼이 아닙니다.
3. 빌드 출력 끝에 **BUILD PASS**가 나와야 합니다. 실제 EXE는 `dist\글클메 번역애드온\글클메 번역애드온.exe`입니다.
4. ZIP 안에는 EXE가 미리 포함되어 있지 않습니다. 처음 한 번은 Python 패키지/공개 데이터/번역 모델 다운로드가 필요합니다.
5. 실패하면 **`BUILD-REPORT.txt`와 `pip-log.txt`**를 보내 주세요. 실패 전후 화면만으로는 원인 특정이 어렵습니다.

### v0.4.17에서 발생한 Windows PySide6 설치 실패 수정

사용자가 보낸 이전 로그는 번역 엔진 오류가 아니라 Python 패키지 설치 중 `Windows Long Path` 오류였습니다. 깊은 다운로드 폴더 아래에 `.venv`를 만들던 문제를 방지하기 위해 이제 빌드용 Python은 **`%LOCALAPPDATA%\KAINMapleTranslator\BuildVenv0418`**에 설치합니다. 앱 EXE 결과는 여전히 압축을 푼 폴더의 `dist` 아래에 생깁니다. 불필요한 **PySide6 Addons 대신 PySide6 Essentials**만 설치합니다.

### 번역 채팅창에서 휠로 지난 채팅 보기

- **자유 플로팅 모드:** 기존처럼 창 위에 커서를 올리면 휠 사용 가능.
- **덮기/좌우 자석 도킹 모드:** 설정 HUD의 **`휠 OFF` 버튼을 `휠 ON`**으로 변경한 다음 번역창 위에서 마우스 휠을 돌리세요.
- 현재 채팅과 확성기는 각각 별도 스크롤 가능. 위로 스크롤한 동안에는 새 OCR 메시지가 도착해도 읽던 위치를 유지합니다. 맨 아래로 내려가면 자동 최신 따라가기가 복구됩니다.
- 게임 위에 덮는 모드는 원래 **클릭 투과**라 마우스 휠도 받을 수 없습니다. **`휠 ON` 중에는 클릭 투과가 잠시 꺼지므로**, 사냥할 때는 다시 `휠 OFF`로 바꾸세요.
- 스크롤바는 표시하지 않습니다. 최근 95개 표시 기록 한도는 유지됩니다.

## 아이템 DB 및 출처

- GMS v83 영문 아이템 ID 10,598개 색인은 빌드 시 공개 WZ XML에서 생성합니다. 한국어 이름이 `0`으로 나오는 것은 별도 한국어 원본이 포함되지 않았음을 뜻합니다.
- 이전 별도 ID 대조 분석에서 **한글 이름이 있는 4,324 ID**를 확인했지만, 해당 한국어 데이터는 제3자 수집본이라 **이 ZIP에 복사하지 않았습니다**. 원본의 사용 허락과 메이플 클래식 월드 버전 차이까지 검토해야 합니다.
- Planet Helper는 한국어 검색에 유용하지만 [이용약관](https://planet-helper.com/gmsclassic/ko/terms/)에서 자동 수집·데이터셋화·재가공을 금지합니다. 해당 사이트의 DB는 스크랩하거나 내장하지 않았습니다.
- [메이플노트 빅뱅](https://xn--o80b01o9mlw3kdzc.com/bigbang)은 구버전 아이템을 참고할 수 있지만, 해당 사이트도 클래식 월드와 다를 수 있음을 밝힙니다. 명시적 재사용 권한은 확인되지 않아 데이터를 일괄 복제하지 않았습니다.
- [Classic Maple Wiki](https://classicmaple.wiki/)에서 CC BY-NC-SA 4.0으로 공개한 JSON 데이터는 기존 v0.4.17 방식대로 빌드 중 다운로드되며 **비상업적 이용 및 저작자 표시 등의 의무**를 지켜야 합니다.
- 사이트 운영자 허락을 받은 한국어 명칭 파일은 앱의 기존 **CSV/JSON 용어집 가져오기**로 반영할 수 있습니다. 별도 데이터 수집/크롤러는 추가하지 않았습니다.

### 허가된 한국어 이름 ID 비교 도구 (오프라인)

한국어 원본 파일을 정식으로 사용할 수 있을 때만, EXE 빌드 후 다음 명령을 폴더 안에서 실행하면 됩니다.

```bat
"%LOCALAPPDATA%\KAINMapleTranslator\BuildVenv0418\Scripts\python.exe" -m scripts.compare_authorized_item_names --korean "C:\path\to\AUTHORIZED-KOREAN-ITEMS.csv"
```

CSV 열은 `item_id,name_ko`, JSON은 `items` 목록 안에 `item_id`/`id`와 `name_ko`가 있으면 됩니다. 결과 `AUTHORIZED-ID-MATCH-REPORT.json`은 전체/매칭/충돌 건수를, `AUTHORIZED-ID-MATCH-CATALOG.csv`는 영문 이름까지 일치시켜 *같은 영문명에 다른 한국어명이 붙은 애매한 경우를 제외한* 앱 입력용 결과를 제공합니다. 파일 내용을 자동으로 웹에 전송하지 않습니다.

## v0.4.22 — 2026-10-24 사용자 현장 오류 4종 수정

- **OCR 정확도 보강**: 화면 속 빨강/노랑/분홍 등 색상 띠를 분리한 뒤, 필요할 때만 추가 OCR을 시행합니다. 영역은 최대 2개이며 게임 전체를 재스캔하지 않습니다. 기존 1차 OCR에서 길게 읽은 문장을 잘린 2차 결과보다 우선시합니다.
- **여러 줄 채팅 결합**: 게임 하단 채팅이 두 줄 이상인 경우 같은 메시지의 연속 줄을 합칩니다. 멀리 떨어진 UI 안내문은 합치지 않습니다.
- **혼합 언어 거래문**: `MEBA 삽니다` → `메바 삽니다`, `[화이트 초코 버니] for 450k. Also have Blank Eye Patc E` → `[화이트 초코 버니] 45만 메소에 팝니다. Blank Eye Patc E도 있습니다`처럼 금액과 확인된 고유명사를 유지합니다. OCR에서 잘린 아이템은 임의로 공식 한글명을 지어내지 않습니다.
- **드롭다운 메뉴**: Qt 활성 팝업이 열려 있는 동안 200ms 주기의 창 우선순위 강제 변경을 잠시 중단합니다. 선택 버튼의 드롭다운 화살표 클릭 영역을 개선합니다.
- **가로 스크롤**: 번역 피드와 설정탭 가로 스크롤바를 비활성화하고 긴 줄은 컨테이너 폭에 맞춰 줄바꿈합니다. **세로 마우스 휠 스크롤은 계속 사용 가능합니다.**
- **기존 기능 보존**: v0.4.21 고확/OBS/아이템 API 동기화/수동 용어집/영→한, 한→영 번역 기능을 유지합니다.

## v0.4.23 — 회색 확성기 인식 추가 (사용자 실게임 캡처 기준)

- **회색 확성기 시각 조건:** 푸른빛이 있는 회색 배경 + 진한 파란 글씨. 노란 하단 테두리는 **검출 조건에 포함하지 않습니다**.
- 이전의 빨강·분홍·노랑·청록 검출 경로는 그대로 유지하며, 회색 채팅창의 배경만으로 고확을 만들지 않도록 **실제 파란 글자 픽셀을 함께 확인**합니다.
- 기본 OCR이 다른 채팅을 인식해도 회색 배경/파란 글씨 후보를 따로 잡아 제한된 영역에서 보조 OCR을 수행합니다. 전체 화면을 추가 캡처하거나 게임 클라이언트에 접근하지 않습니다.
- OCR 진단 창에 **회색 확성기 후보 영역** 수를 보여 줍니다. 검출되면 상단 확성기 번역창(OBS 포함)으로 분류합니다.
- 사용자 캡처 이미지의 색상 픽셀을 로컬 분석하여 감지 확인했고, 다색 고확 및 회색 UI 오탐 방지 회귀 테스트를 추가했습니다.
- **게임 화면 실시간 OCR 검증은 아직 하지 못했습니다.** 사용자가 선택한 *하단 채팅 OCR 영역 안에* 회색 확성기가 표시되어야 작동합니다. 지정 영역 밖의 메시지는 수집하지 않습니다.
- 테스트 261/261 PASS (Linux Python), Windows EXE 빌드 및 실게임 동작은 별도 검증 필요.
