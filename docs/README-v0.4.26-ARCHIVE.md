# 글클메 번역애드온 v0.4.26

v0.4.25에서 실제 채팅이 누락되던 문제를 수정한 독립 빌더입니다. 기존 UI·OBS·아이템 사전·한국어→영어 입력 번역을 유지합니다.

## 실행

1. 이전 번역 프로그램을 종료합니다.
2. ZIP 전체를 새 폴더에 풉니다.
3. `BUILD-WINDOWS.bat`를 실행합니다.
4. 성공 후 `dist\글클메 번역애드온\글클메 번역애드온.exe`를 실행합니다.
5. 게임 하단 채팅의 닉네임·구분 기호·본문을 모두 포함해 인식 영역을 지정합니다. 과거 로그 판정에는 오른쪽 스크롤바도 포함해야 합니다.

이전 버전 폴더는 필요 없습니다. 최초 빌드에는 Python 패키지와 영↔한 모델 다운로드용 인터넷이 필요합니다. OCR 모델은 포함했습니다. 실행 중 번역은 오프라인이며, ONNX 진단 전송은 초기화 전부터 비활성화합니다. Windows에서 미리 빌드한 EXE가 들어 있는 ZIP은 아닙니다.

## 이번 수정

- 줄 단위 분리 → 배경 추정·제거 → 확대 → 변경된 글줄만 OCR을 유지하면서 실제 누락 원인을 수정했습니다.
- 닉네임 뒤 `;` / `:` 및 전각 기호를 구분자로 받습니다. 구분자와 앞쪽 이름을 먼저 확인하고 본문을 따로 읽습니다. 본문·아이템 안의 기호를 다시 닉네임 구분자로 사용하지 않습니다.
- 채널 아이콘은 필수 조건이 아닙니다. 아이콘이 있으면 흰 CH 상자의 실제 범위만 제외하며, CH 글자가 깨져도 이름·본문을 버리지 않습니다. 배지 없는 줄도 구분 기호로 나눕니다.
- 1픽셀 채팅창 테두리와 스크롤 레일 테두리가 여러 줄을 하나로 연결하던 문제를 수정했습니다.
- 노란 배경을 빨간 시스템 공지 전처리로 오인해 검은 닉네임·본문이 지워지던 문제를 수정했습니다.
- 배경색은 양자화 최빈색으로 추정하고 주변 세로 5행으로 안정화합니다. 긴 글자 줄이 배경 중앙값을 끌어내려 가짜 가로줄이 생기던 현상을 줄였습니다.
- 원본에 색상 배경이 있는 줄과, 어두운 배경에서 글자 자체에 색상이 있는 줄을 확성기로 분류합니다. 흰 본문에 닉네임이나 아이템만 색상이 있는 경우는 일반채팅을 유지합니다. 시스템 획득 공지 제외와 빨간 유저 확성기 유지를 계속 적용합니다.
- `[ ]` 안에 한글이 포함된 아이템명은 영문·스탯이 섞여 있어도 통째로 보존합니다. 한글만 있는 메시지도 표시하며, 영문 거래 부분이 있으면 그 부분을 번역합니다.
- 쉼표 없는 아이템·가격 목록, 링크 뒤 `S> 150k`, `offer please`, 명확한 판매 목록의 슬래시 구분을 보완했습니다. 금액은 모델에 맡기지 않고 정확히 변환합니다.

이름/본문 캐시·거래 문장 틀 캐시·묶음 번역·워밍업·동적 출력 길이 제한·반복 방지·CPU/p95 진단 등 v0.4.25 기능은 유지합니다. 이전 기능 설명은 `docs/README-v0.4.25-ARCHIVE.md`에 있습니다.

## 확인한 결과

이번에 올린 실제 화면의 네 채팅을 같은 OCR 모델로 재생했습니다. 이전 버전은 네 줄 모두 최종 메시지 분리에서 탈락했고, 수정 후에는 네 줄의 닉네임·본문·가격·색상 분류가 들어옵니다. 이 네 문장은 규칙으로 번역되어 신경망 번역 호출이 필요하지 않았습니다. 모델 초기화 후 같은 화면을 다시 검사할 때 OCR 재호출이 없는 것도 확인했습니다.

`VALIDATION-v0.4.26.md`, `PERFORMANCE-v0.4.26.json`, `TEST-RESULTS-v0.4.26.txt`, `OCR-REAL-CROP-REPLAY-v0.4.26.txt`에 결과를 기록했습니다. 검사를 생략하거나 빌드 실패를 무시하지 않습니다.

실제 Windows 게임 실행 중의 FPS·연속 수집·EXE 생성은 이 환경에서 검증하지 못했습니다. 한 장의 화면 재현 성공을 모든 글꼴·배율·한글 OCR의 완벽한 인식으로 보장하지 않습니다. 닉네임이 영역 밖이거나 화면 밖으로 지나간 채팅은 추측하지 않습니다.
