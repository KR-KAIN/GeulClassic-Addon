# 글클메 번역애드온 v0.4.16 — 공개 Classic World DB + 빨간 확성기 인식 (v0.4.13 기반)
제작자 KAIN

## 이번 패치 핵심
- **기존 v0.4.13 UI, OCR, OBS, 작은 플로팅 번역창, 설정/용어집 유지**.
- **빨간 확성기 수집 보강**: 진한 적색 띠와 적색 글자를 구분, 일반 채팅
  OCR에서 글자가 읽혀도 빨간 영역은 별도로 재인식. 일반 대화와 함께 기록하며
  확성기 상단 패널로 분리. 빨간색만으로 고확/아확 아이템 종류를 단정하지 않음.
- 빨간 확성기는 반드시 **게임 하단 채팅 인식 영역 안에 포함**되어야 합니다.
  게임 상단 등 채팅 영역 바깥의 메시지는 인식하지 않습니다.
- `BUILD-WINDOWS.bat` 실행 시 Classic Maple Wiki에서 게시한 JSON 내보내기 파일
  (아이템·몬스터·맵·NPC·퀘스트·상점·직업·제작·시스템·패치·빌드)을 가져와
  EXE의 오프라인 리소스에 함께 포함합니다.
- 아이템 영문 정식 제목을 거래 채팅에서 식별하며, 직접 등록된 한글 아이템명과
  기존 수동 사전이 최우선입니다. 공개 DB에는 한글명이 대체로 없어 로컬 AI
  번역 결과는 **추정명**이고 공식 현지화로 보증되지 않습니다.
- 공개 DB 파일은 **CC BY-NC-SA 4.0 비상업적 이용 전용**입니다.
  `OPEN-DATA-LICENSE.md`에서 출처·조건·원저작권 정보를 확인하세요.

## 사용법
1. ZIP 하나만 원하는 폴더에 풀고 `BUILD-WINDOWS.bat` 더블클릭.
2. 설치 중 파이썬/모델/아이템 DB 다운로드에 네트워크가 필요합니다.
3. `OPEN-DATA-REPORT.json`에서 각 공개 데이터 항목 수, 받은 시각, SHA256 확인.
4. Windows EXE: `dist\글클메 번역애드온\글클메 번역애드온.exe`.
5. 게임 실행 → 채팅창 OCR 위치 지정 → 번역 실행.

네트워크 차단 등의 이유로 공개 DB 다운로드가 실패해도 앱 빌드는 진행되지만,
그 경우 `OPEN-DATA-REPORT.json`에 **unavailable**로 명시되며 해당 새 데이터는
포함되지 않습니다. 모두 받아진 것을 확인하려면 `required_data_available: true`
여야 합니다. 다국어 아이템명은 설정에서 인증된 CSV/JSON 사전을 추가할 수 있습니다.

**주의:** Planet Helper, MeowDB를 크롤링/복제하지 않았습니다. 게임 파일 변경,
서버 접근, 메모리 후킹도 없습니다. 기존 기능을 재구현한 다른 앱이 아니라
v0.4.13 독립 소스 패키지에서 기능을 추가한 버전입니다.

# 글클메 번역애드온 v0.4.13 — 대량 아이템 ID 색인
제작자 KAIN

**중요:** 이 패키지는 NiaMeowDB 전체 5천여 개 항목을 수집한 것이 아닙니다. 그 사이트의 무허가 자동 수집을 실행하지 않습니다. 대신 별도 공개 GMS v83 클라이언트 String.wz XML에서 아이템 ID·영어 이름을 수집하여 로컬 색인을 만들 수 있습니다. 현재 글로벌 클래식 월드와 버전 차이가 있으며, 일부 현재 게임 아이템이 없을 수 있습니다.

## 독립 빌드
1. ZIP 전체 압축 해제.
2. `BUILD-WINDOWS.bat` 실행: Python 설치/의존성/영어↔한국어 오프라인 모델 준비 및 EXE 빌드를 진행합니다. 이 과정에서 공개된 GMS v83 아이템 XML 6개를 한 번 내려받아 전체 ID 목록을 만들도록 **시도**합니다. 네트워크 실패 시 빌드는 진행되나 아이템 DB는 생성되지 않을 수 있습니다.
3. `ITEM-ID-REPORT.json`에서 **전체 ID 수와 한국어 이름이 확보된 수**를 각각 확인하세요. 숫자가 없으면 `ITEM-ID-BUILD-LOG.txt` 확인.
4. EXE는 `dist\글클메 번역애드온\글클메 번역애드온.exe`.

## 한국어 아이템 정확도 높이기
GMS v83 원본은 영문명 중심입니다. 공식 한국어명을 확보한 XML이 있으면 (최초 사용자가 제공하거나 이용 허가된 자료) `item-sources/ko/`에 `Eqp.img.xml`, `Consume.img.xml` 등 파일을 넣고 `BUILD-ITEM-DB.bat`를 실행하면 **동일한 게임 아이템 ID로만 영/한명을 매칭**합니다. 게임 메모리나 게임 파일은 수정하지 않습니다.

기존 설정의 `아이템 DB 파일 가져오기(CSV/JSON)`은 그대로 지원하며, 사용자가 지정한 검증된 한글명이 생성 색인보다 우선합니다. 이름이 없거나 ID가 안 맞으면 거짓 이름으로 번역하지 않습니다.

**한계:** 이 스냅샷은 실제 글로벌 클래식 월드 전체 5156개 ID 목록과 일치한다고 인증한 것이 아닙니다. Windows 빌드/실제 게임 번역 성공도 여기서는 미검증입니다.

출처(아이템 원본): https://github.com/andrenogrib/gms_v83_wztoweb  (공개 GMS v83 아이템 String.wz XML)

## 영문 ID만 있고 한국어명이 없는 경우
해당 **정확한 아이템 영문명이 거래글에 등장한 경우에만** 오프라인 번역 모델로 한국어명을 1회 추정하고 이후 캐시합니다. 이는 공식 아이템명이 아닐 수 있습니다. 사용자가 추가한 CSV/JSON 확정 번역명이 항상 더 높은 우선순위를 갖습니다. 오류가 있는 번역은 사용자가 CSV 사전으로 교정해야 합니다.

## v0.4.13 번역 안정성 개선
- 전체 웹 주소나 도메인이 포함된 줄은 번역 모델에 보내지 않고 원문 보존합니다. `mesolane.gg`가 `메소`로 깨지는 현상 방지.
- 유저가 제공한 거래글에서 자주 나온 캐시·장비 이름을 수작업 사전으로 보강했습니다(공식 한글명이 아닐 수 있음).
- 여러 개의 아이템명 구분, `pm` 약어, 미강화(clean), +강화 수치 및 금액을 보존합니다.
- 웹 크롤링: NiaMeowDB의 5,156개 전체 복제본은 **포함되지 않습니다**. Mesolane의 아이템 목록도 **통째로 수집하지 않았습니다**.
- 아이템 ID의 대량 로컬 색인은 공개된 구버전 GMS WZ 스냅샷을 Windows에서 `BUILD-ITEM-DB.bat`로 가져올 수 있으나, **영문 ID 전부가 한국어명을 가진 것은 아닙니다**.
- 기존 설정과 제작자 KAIN, 프로그램명 글클메 번역애드온을 유지합니다.


## v0.4.16 Windows 빌드 창 바로 닫힘 대응

- ZIP 내부에서 파일만 더블클릭하지 말고, ZIP 전체를 폴더로 **압축 해제**한 뒤 `BUILD-WINDOWS.bat` 실행.
- 배치 파일이 명령 프롬프트(cmd /K) 안에서 동작해 실행 실패 시에도 창이 유지됩니다.
- 초기에 실패하면 `BUILD-STARTUP-LOG.txt` 확인. 빌드 시작 이후에는 `BUILD-REPORT.txt` 확인.
- 그래도 창이 닫히면 `OPEN-BUILD-CONSOLE.bat` 실행.
- 로컬 Windows EXE 빌드는 이곳에서 검증하지 않았으며, Windows PC에서 보고서 확인 필요.
