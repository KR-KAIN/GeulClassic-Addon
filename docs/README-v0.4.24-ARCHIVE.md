# 글클메 번역애드온 v0.4.24

v0.4.23의 기존 UI/아이템 사전/한국어→영어 입력 번역/OBS 기능을 유지한 독립 Windows 빌드 패키지입니다. 이전 버전 폴더는 필요 없습니다.

## 실행 방법

1. 실행 중인 이전 번역 프로그램을 종료하세요.
2. ZIP 전체를 새 폴더에 풀고 `BUILD-WINDOWS.bat`를 실행하세요.
3. 빌드 성공 후 `dist\글클메 번역애드온\글클메 번역애드온.exe`를 실행하세요.
4. 실제 게임 하단 채팅 내용과 닉네임이 모두 포함되도록 인식 영역을 지정하고 번역을 켜세요.

기존 사용자 설정과 직접 등록한 아이템 사전은 기존 사용자 데이터 경로에서 이어서 읽습니다. 이미 빌드된 Windows EXE를 제공하는 ZIP은 아닙니다. 최초 빌드에는 Python 패키지와 영↔한 번역 모델을 받기 위한 인터넷 연결이 필요합니다. 완성된 앱의 OCR/번역은 로컬에서 실행합니다. 이번 ZIP에는 검증한 OCR 모델 3개를 포함했습니다.

## 바뀐 인식 경로

- 화면 캡처는 기본 80ms 간격으로 별도 스레드에서 감시합니다. 글자/줄바꿈 위치를 찾아 줄을 자르고 배경과 글자색의 차이로 흰 바탕·검은 글씨를 만듭니다.
- 잘라낸 줄은 인식 모델의 입력 높이로 확대해 읽습니다. RapidOCR의 문자 인식 단계만 일괄 호출하고, 일반 경로에서는 글자 위치 검출과 회전 판정을 생략합니다.
- 줄 이미지 해시로 인식 결과를 보관합니다. 스크롤 때문에 위치만 옮겨진 줄은 다시 OCR하지 않습니다. 판독이 불확실하면 기존 전체 검출 경로로 복구합니다.
- 청록/노랑/분홍/빨강/회색 등의 배경색과 글자색을 별도로 읽습니다. 선택 영역이 실제 채팅보다 넓어도 문자 주변 배경색으로 고확 판정을 한 번 더 확인합니다.
- 기본 다국어 모델에서 한글이 불확실한 경우 한글 전용 모델로 보완합니다. 숫자가 달라지는 후보는 채택하지 않습니다.

## 원문에 없는 일반채팅 방지

- 일반채팅은 연속된 별도 화면에서 같은 닉네임과 원문이 확인된 뒤 등록합니다. 일반채팅 신규 표시에 약 80~240ms의 확인 지연이 생길 수 있습니다.
- 고확을 읽은 뒤 잠깐 색상 판정이 실패해도 같은 문장을 일반채팅으로 옮기지 않습니다. 채널 뱃지가 확인되면 배경색이 불확실해도 일반채팅으로 보내지 않습니다.
- 닉네임이 잘린 채 남은 CH05/CHOS/cHos 같은 채널 표시를 사람 이름으로 만들지 않습니다. 실제 닉네임이 영역 밖에 있으면 그 메시지를 추측해서 등록하지 않습니다.
- 배경 종류가 다른 줄은 앞 메시지에 이어붙이지 않습니다. 가격/레벨 숫자가 달라지면 새로운 메시지로 취급합니다.
- 사용자의 최종 요청에 따라 아이템 획득 시스템 공지는 표시하지 않습니다. 빨간 유저 확성기 채팅은 계속 처리합니다.

## 번역 지연과 약어

- 번역은 최대 8문장씩 묶어 같은 로컬 모델로 처리합니다. 게임 용어/인사/파티 모집 등 확실한 규칙은 모델 대기열을 거치지 않습니다.
- 동일 문장 번역 결과는 재사용하지만 닉네임별 메시지는 모두 보존합니다. 기존 12건 제한에서 새 문장이 조용히 빠지던 경로를 제거했습니다.
- LFM/LFG, KPQ/LPQ, BRB, CC, IDK, RN, TYSM, OBO 등의 빠른 처리를 보강했습니다. 가격, 확률, 링크, 아이템명에 유사 단어를 강제 대입하지 않습니다.
- 번역이 늦게 끝나도 화면과 OBS에 원문 수집 순서대로 삽입합니다.
- 캡처 버퍼나 번역 대기열이 감당할 수 없는 경우 진단/상태로 알립니다. 번역 대기 초과/번역 실패 시 원문을 명시적으로 표시합니다. 화면에 보이지 않은 문장까지 복구할 수 있는 구조는 아닙니다.

## 글자색 / 진단

설정 → 채팅 디자인 → `원문 채팅 글자색 유지`를 끄면 직접 지정한 글자색을 사용할 수 있습니다. 고확 배경색 분류와는 별개입니다.

`OCR 진단`의 상세 내용을 펼치면 OCR 시간, 줄 캐시 재사용 수, 신규 인식 줄 수, 검출 복구 횟수, 번역 대기, 프레임 지연, 과부하 횟수를 볼 수 있습니다.

## 검증 범위

`VALIDATION-v0.4.24.md`와 `PERFORMANCE-v0.4.24.json`을 확인하세요. 사용자 실제 캡처 3종을 재생하는 검사가 포함됩니다. Linux CPU 테스트/Qt 화면 없는 검수와 Windows 실게임 검수는 다릅니다. 이 환경에서 Windows EXE 생성 및 실게임 연속 플레이를 검증하지 않았습니다. 작은 I/l 구별이나 매우 빠르게 지나가는 채팅을 포함해 100% 정확도/무누락을 보장하지 않습니다.

기존 기능과 아이템 DB 사용법은 `docs/README-v0.4.23-ARCHIVE.md`를 참고하세요.
