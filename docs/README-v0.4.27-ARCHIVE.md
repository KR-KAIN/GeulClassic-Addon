# 글클메 번역애드온 v0.4.27

v0.4.26 기반의 주문서·공격력 번역 보완 및 선택적 OCR 재확인 패치입니다. 기존 UI·OBS·한국어→영어 입력·용어집·일반/확성기 분류를 유지합니다.

## 사용

1. 이전 번역 프로그램을 종료합니다.
2. ZIP 전체를 새 폴더에 풉니다.
3. `BUILD-WINDOWS.bat`를 실행합니다.
4. 성공 후 `dist\글클메 번역애드온\글클메 번역애드온.exe`를 실행합니다.
5. 인식 영역에는 하단 채팅의 닉네임·구분 기호·본문을 함께 넣습니다.

이전 버전 폴더는 필요 없습니다. 최초 빌드에는 Python 패키지·영↔한 번역 모델 다운로드용 인터넷이 필요하며 OCR 모델 3개는 포함했습니다. 실행 중 번역은 오프라인입니다. 이 ZIP은 Windows에서 미리 빌드한 EXE가 들어 있는 패키지가 아닙니다.

## 주문서와 능력치

- 여러 주문서·아이템이 한 줄에 섞여 있어도 알려진 장비·능력치·성공률 구간을 각각 읽습니다.
- `glove att 60% / claw att 100%` → `장갑 공격력 60% 주문서 / 아대 공격력 100% 주문서`.
- `ATT/ATK/WATK/W.ATT`와 `M.ATT/MATT/MATK`를 구분하고 마력을 공격력으로 바꾸지 않습니다. 띄어쓰기가 붙은 `gloveATT60%`, 숫자 앞뒤의 `8att`·`ATK+8`도 처리합니다.
- `+2` 강화 표시를 무조건 공격력 +2로 해석하지 않습니다. `Kfan +2`는 `태극부채 +2`로 두고, `claw att +2`처럼 능력치가 명시된 경우만 공격력 +2로 표시합니다.
- 성공률·부호·능력치 값이 출력에서 사라지거나 다른 능력치로 옮겨지면 그 결과를 채택하지 않고 해당 부분을 보존합니다. 누락된 확률이나 숫자를 추측해서 채우지 않습니다.
- 한글이 들어간 `[아이템 이름]`은 영문·스탯이 섞여 있어도 그대로 보존합니다. 영어 링크도 완전하게 확인되는 주문서 이름만 해석하며 미확인 이름은 남겨 둡니다.
- `[Glove for ATT 60%] PMO`처럼 매매 기호가 없어도 알려진 주문서 링크와 제안 문구를 처리합니다. 여러 GFA/GMA, 장비별 STR/DEX/INT/LUK/체력/점프/이동속도 주문서도 보완했습니다.
- 혼돈(Chaos) 표기만 보고 성공률을 자동으로 10%라고 만들던 경로를 수정했습니다.

## OCR 보완

글줄 분리·배경 제거·확대·변경된 줄만 인식·닉네임/본문 분리·캐시를 유지합니다. 주문서/능력치 줄에서는 줄 평균 점수가 높아도 관련 문자 신뢰도가 낮으면 원본 색상 이미지로 추가 확인합니다. 검출 모델을 다시 돌리는 대신 잘라 둔 줄의 인식 단계만 사용합니다.

재확인 결과의 숫자열·성공률·부호가 원래 판독과 다르거나, 이미 읽힌 장비/능력치/주문서 단어를 잃으면 채택하지 않습니다. 사전에서 가까운 숫자나 아이템을 강제로 고르는 방식은 사용하지 않습니다. 숫자 불일치는 진단에 기록하고 약한 결과로 캐시해 다음 화면에서 재확인할 수 있게 합니다.

추가 진단 항목: `critical_retry_rows`(문자 신뢰도 재확인), `numeric_retry_disagreements`(숫자/부호 불일치), `term_retry_rejections`(기존 용어를 잃는 재확인 거절). 변경 없는 안정적인 줄은 OCR을 다시 부르지 않습니다.

## 확인 범위

390개 검사, 기존 실제 채팅 캡처 재생, 실제 주문서 OCR→번역 합성 재생, EN↔KO 실제 모델 추론을 통과했습니다. 연구 과정·채택/제외 이유와 측정값은 `RESEARCH-SCROLL-OCR-v0.4.27.md` 및 `OCR-RESEARCH-v0.4.27.json`에 있습니다.

최신 첨부 화면에는 번역창만 있어 실제 게임 원문을 알 수 없습니다. 화면에 남은 영문 표현을 재구성한 입력으로 번역 누락을 재현했으며, 원문 OCR까지 검증했다고 주장하지 않습니다. 실제 Windows 게임의 연속 수집·FPS·EXE 빌드는 이 환경에서 미검증입니다. 이전 버전의 설정·사용자 아이템 사전은 이어서 사용합니다.
